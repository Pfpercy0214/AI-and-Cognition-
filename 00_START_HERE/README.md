# Start here: shared research method

**Methodology edition 1.1 - 3 October 2026.**

Read the [local AI onboarding brief](AI_Onboarding_Brief.md) first. It describes a metrological approach to ARK collaboration: define the quantity, expose the observation-to-output mapping, account for uncertainty, and test consequences without prescribing belief in the framework.

> Measured-input prediction, reciprocal relations, and simultaneous closure are legitimate when the actual information flow supports the claim. A circularity objection must identify the target leak or answer-forcing choice; agreement alone does not establish a unique mechanism.

Then read [Prediction, closure, and mechanism](https://github.com/Pfpercy0214/aetherwave-unified-theory/blob/110e554d944eeda6b0e14795f45a94b8a27a805e/00_START_HERE/Prediction_Closure_and_Mechanism.md) and the [full epistemic charter](ARK_Epistemic_Charter.md). Before implementation, obtain the actual task-specific equations, measurement mappings, model version, and current claim and negative-result records. This protocol does not supply missing physics.
