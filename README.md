>
> Read the [local onboarding brief](00_START_HERE/AI_Onboarding_Brief.md) and the [version-pinned full charter](00_START_HERE/ARK_Epistemic_Charter.md). Root [AGENTS.md](AGENTS.md) supplies repository-level research guidance.

This repository starts with a shared epistemic research protocol for human and AI collaboration on ARK-related work. Its purpose is to make reasoning, measurement assumptions, calibration, testing, and correction inspectable. It is not evidence that ARK's physical or cognitive interpretations have been established, or that an AI reading these files has been retrained.

Independently characterized measured inputs can support genuine prediction through fixed relationships. Reciprocal equations, coupled closure, and legitimate calibration are not automatically circular. Trace actual target leakage and answer-selecting choices while recognizing useful conditional and cross-domain inference.

The physics repository maintains the canonical full charter. This repository provides local first-read guidance and pins the detailed material to an identified edition so that the two entry points do not silently diverge.
